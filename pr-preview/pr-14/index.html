My foods

Add your own foods, meals or recipes. Copy the prompt into ChatGPT (or similar), add your foods after it, and paste the JSON it gives back here. Each food is entered per unit (one chip, one slice, one bowl), and you pick how many units when you use it. They're saved in this browser only, so use Export to keep a copy or move them to another device. Adding a food with the same name replaces it.
